# UI/UX Pro Max Explorer — Master Design System Index

This directory contains one design system file per curated system design in the Explorer app.
Each file was generated by the `ui-ux-pro-max` skill's reasoning engine against the specific
product type and style keywords for that system.

## Hierarchical Usage

1. When building or extending a specific system design, **start with its page file** below.
2. The page file's rules **take precedence** over any global defaults.
3. For cross-cutting concerns (accessibility, animation timing, z-index scale), refer back to the skill's `ux-guidelines.csv`.

## Global Design Principles (applies to all systems)

### Shell
- Background: `linear-gradient(135deg, #0f0f1a, #1a0a2e, #0f1a2e)` (fixed)
- Sidebar: Dark glassmorphism — `bg-white/5 backdrop-blur-xl border-r border-white/10`
- Cards: `bg-white/10 backdrop-blur-sm rounded-2xl border border-white/15`
- App accent: Indigo `#6366F1`

### Interaction
- Hover transitions: `150–250ms ease-out`
- Focus: `focus-visible:ring-2` (never `focus:ring-2`)
- All clickable elements: `cursor-pointer`
- Animations respect `prefers-reduced-motion`

### Accessibility
- Minimum contrast: 4.5:1 for normal text (WCAG AA)
- All SVG icons: `aria-hidden="true"` when decorative
- Interactive elements: `aria-label` when icon-only
- Tab order matches visual order

### Data
- All design data loaded from `/public/data/*.csv` via Papa Parse
- No hardcoded design tokens in components — always pass from `SystemDesign` config object
