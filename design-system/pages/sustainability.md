## Design System: Sustainability ESG

Generated from ui-ux-pro-max skill · Product: Sustainability / ESG

### Pattern
- **Name:** Impact-First Landing + Data Dashboard + Annual Report
- **Sections:** 1. Mission hero (impact numbers), 2. ESG metrics dashboard, 3. Annual report with scoring
- **CTA Placement:** Hero (Start ESG Report) + Dashboard (Download) + Report (Export PDF)
- **Conversion Focus:** Quantified impact builds credibility. Letter-grade scoring (A/B/C) is scannable for stakeholders.

### Style
- **Primary:** Organic Biophilic — natural textures, leaf/growth motifs, earth-tone palette
- **Secondary:** Minimalism — clean data presentation, no decorative distractions
- **Key Effects:** Smooth progress bar fills, subtle green gradient on positive metrics, 200ms transitions

### Typography
- **Heading:** Merriweather (300/400/700 + italic) — editorial, trustworthy, report-quality
- **Body:** Inter (300/400/500/600) — neutral and readable for dense data
- **Google Fonts:** `https://fonts.google.com/share?selection.family=Merriweather:ital,wght@0,300;0,400;0,700;1,300|Inter:wght@300;400;500;600`

### Anti-patterns
- Don't use dark mode — green themes are best in light mode
- Avoid excessive animation — reports must feel serious and authoritative
- Don't use red/danger colors for environmental metrics — it sends wrong message
